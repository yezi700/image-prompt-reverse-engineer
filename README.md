## 🌟 这个仓库有什么？

目前包含两个核心 Skill：

### 🧠 1. Image Prompt Reverse Engineer

把参考图片逆向拆解成高质量 AI 生图提示词。

重点分析：

- 主体身份与数量
- 姿势与动作
- 人物 / 物体之间的关系
- 构图与视角
- 光线方向与阴影
- 色彩关系
- 材质
- 景深
- 空间层次
- 最影响“像不像”的视觉锚点

适合用于：

**GPT Image / Qwen-Image / Seedream / FLUX / SDXL / Gemini Image**

👉 [查看主 Skill](./SKILL.md)

---

### 👩 2. Beauty Image Defaults

专门用于成年女性人像、写真和女性角色提示词的默认画像与美术指导。

核心不是“20 岁网红脸”，而是：

> **轻熟女 · 人妻感 · 熟女**

并且会根据用户的描述自动切换档位。

👉 [查看 Beauty Image Defaults](./skills/beauty-image-defaults/SKILL.md)

# 🔥 三档自动切换

| 模式 | 默认视觉年龄 | 核心气质 | 典型关键词 |
|---|---:|---|---|
| 🌿 **轻熟女** | 27–34 | 年轻成熟、都市、知性、精致 | 通勤、白领、年轻姐姐、都市知性 |
| ☕ **人妻感** | 30–38 | 温柔、亲和、生活感、松弛感 | 居家、咖啡、做饭、温柔成熟、生活方式 |
| 🥂 **熟女** | 35–45 | 成熟、从容、自信、优雅 | 成熟姐姐、贵气、熟女、强气场 |

### 自动路由示例

```text
“都市白领，精致通勤，年轻姐姐”
→ 轻熟女

“温柔居家，在厨房喝咖啡，有生活感”
→ 人妻感

“成熟女性，优雅、自信、有贵气”
→ 熟女
```

没有足够线索时：

> **默认走「人妻感」模式，约 32–36 岁视觉方向。**

# 🧬 最重要的优先级

```text
用户当前要求
    ↓
当前参考图
    ↓
已锁定人物设定
    ↓
三档自动模式
    ↓
通用默认画像
    ↓
一般审美建议
```

这意味着：

- 有参考人物时，不会被默认模板强行换脸
- 不会因为“人妻感”就擅自添加婚戒、丈夫或孩子
- 不会因为“熟女”就自动增加皱纹或老态
- 不会因为“更漂亮”就擅自改年龄、脸型和身材

---

# 💡 我们对三个词的定义

> **轻熟女 ≠ 少女**

> **人妻感 ≠ 已婚身份**

> **熟女 ≠ 老态**

> **成熟感 ≠ 增加皱纹**

> **女人味 ≠ 过度裸露**

人妻感在这里是一种 **视觉气质标签**：

**温柔 + 知性 + 成熟 + 亲和 + 生活感 + 松弛感**

而不是婚姻状态判断。

# 🛡️ Reference First

当用户提供人物参考图时，Beauty Image Defaults 会优先保留：

- 五官
- 脸型
- 年龄观感
- 肤色
- 发色
- 发型
- 眼镜状态
- 可见身材比例
- 人物气质

默认画像只负责补充 **参考图和用户都没有指定的信息**。

核心原则：

> **先保身份，再做美术。**

# 🎯 设计目标

这个项目追求的不是无限堆砌“8K、masterpiece、ultra detailed”。

更关注真正影响画面的因素：

**身份一致性**

**人物年龄与气质**

**构图**

**动作**

**光线**

**材质**

**空间关系**

**视觉层次**

最终目标：

> **让提示词更像一个懂摄影、懂人物、懂 AI 生图的视觉导演写出来的，而不是关键词垃圾桶。**
