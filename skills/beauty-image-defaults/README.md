# beauty-image-defaults

用于成年女性人像提示词生成与编辑的默认画像 Skill。

## 三档自动模式

- **轻熟女**：约 27–34 岁视觉方向；年轻成熟、都市知性、精致轻盈。
- **人妻感**：约 30–38 岁视觉方向；温柔成熟、亲和、生活感、松弛感。默认模式。
- **熟女**：约 35–45 岁视觉方向；成熟、从容、自信、优雅、有存在感。

年龄范围只在没有参考人物、用户也没有明确年龄时使用。

## 自动切换示例

- “都市白领、精致通勤、年轻姐姐” → 轻熟女
- “温柔居家、喝咖啡、生活感、松弛” → 人妻感
- “成熟姐姐、熟女、贵气、从容自信” → 熟女
- 没有足够线索 → 默认人妻感，约 32–36 岁视觉方向

## 核心优先级

`用户当前要求 > 当前参考图 > 已锁定人物设定 > 自动档位 > 通用默认画像 > 一般审美建议`

“人妻感”只代表成熟、温柔、生活化的视觉气质，不自动推断婚姻状态，也不自动加入丈夫、孩子或婚戒。
